# Clerk 사용자용 보고서 목록

이 폴더는 Clerk가 사용자에게 전달하는 한글 운영 보고서와 smoke 실행 결과를
보관한다. 내부 작업 증거는 `.agents/env-status/`에 계속 보존한다.

## 작성 규칙

- 개별 보고서는 `개별/`에 시간순으로 추가하며 삭제하거나 덮어쓰지 않는다.
- 새 개별 보고서 5건마다 그 5건을 `통합/`의 통합 보고서 하나로 정리한다.
- 현재 통합 대기 건수는 **3건**이다. 다음 통합은 개별 보고서 5건이 되는 시점에 작성한다.
- smoke 실행은 seed 수와 무관하게 `smoke_run.md`에 한 행씩 누적하고, 가능한 경우
  HyperGC 논문값 대비 차이도 함께 기록한다.
