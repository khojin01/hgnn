# PhenomNN Torch 2.7 호환성 확인

- 작성 시각(KST): 2026-09-10
- 대상: PhenomNN, `hgnn-pyg`
- 현재 상태: 진행 중

## 발생한 문제

- Torch 2.7의 `ReduceLROnPlateau`가 더는 `verbose` 인자를 받지 않아 PhenomNN이 학습
  시작 전 실패했다.

## 조치 내용

- Torch/PyG 및 PhenomNN import를 확인했고, Cora-CA GPU smoke로 정확한 실패 지점을
  재현했다.
- AllSet·EDHNN·H-GD·HyperGCN이 사용하는 공유 `hgnn-pyg`의 Torch 버전은 변경하지 않았다.

## 현재 상태

- 진행 중: `verbose` 인자를 제거하는 범위 제한 코드 호환성 수정 또는 별도 legacy runtime이
  필요하다.
- 해결 불가: 현재 공유 환경을 하향 조정하는 방식은 다른 smoke-pass 모델을 손상시킬 위험이
  있어 적용하지 않는다. 분리 환경 또는 코드 수정 권한이 주어지면 재검토한다.

## 다음 담당자

- 사용자: PhenomNN의 범위 제한 코드 호환성 수정 또는 별도 legacy 환경 생성 여부 결정.
- env-builder: 승인 시 PhenomNN 전용 호환 환경 검토.
- clerk: 재시도 결과를 `smoke_run.md`에 누적.

`△ (해결중)`은 아직 실행하지 않았거나 환경/데이터/권한 해결을 기다리는 task다.
