# UniGCN2 환경 및 node smoke 검증

- 작성 시각(KST): 2026-09-10
- 대상: UniGCN2, `hgnn-legacy`
- 현재 상태: 진행 중

## 발생한 문제

- 코드 실행 자체의 환경 문제는 발견되지 않았다. 단일 seed의 표준편차 `nan`은 표본 수 1개로 인한 정상 경고다.

## 조치 내용

- `hgnn-legacy`에서 UniGCN2 import 및 GPU0 Cora-CA 1-seed/15-epoch smoke를 실행했다.

## 현재 상태

- 해결됨: 종료 코드 0으로 실행됐고 final test accuracy는 22.33%다.
- 진행 중: T3 기준 55.3 ± 5.3% 대비 -32.97%p다. 단일 seed·짧은 epoch 결과이므로 20-split 재현 검증이 필요하다.

## 다음 담당자

- env-checker: UniGCN2 edge smoke 및 20-split 재현 검증.
- clerk: 후속 실행 결과를 `smoke_run.md`에 누적.
