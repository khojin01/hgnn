# SEHSSL 설정 파일 누락 확인

- 작성 시각(KST): 2026-09-10
- 대상: SEHSSL, `hgnn-pyg`
- 현재 상태: 해결 불가

## 발생한 문제

- SEHSSL 학습 스크립트가 실행 초기에 읽는 `SEHSSL/config.yaml` 파일이 체크아웃에 없다.

## 조치 내용

- `node.sh`에서 Cora-CA node 실행 파라미터를 확인하고 GPU0, 1 seed, 15 epoch smoke를
  시도했다.
- 인자 파싱과 런타임 의존성은 통과했으나 설정 파일을 읽는 단계에서 실패했다.

## 현재 상태

- 해결 불가: 누락된 `config.yaml` 원본이 제공되기 전에는 데이터별 batch size 등 필수
  설정을 임의로 추정할 수 없다. 원본 설정 파일을 복원하면 즉시 재시도한다.

## 다음 담당자

- 사용자/소스 담당자: `SEHSSL/config.yaml` 원본 제공 또는 복원.
- env-checker: 복원 후 node·edge·cluster smoke 실행.
- clerk: 재시도 결과를 `smoke_run.md`에 누적.

## 전체 모델 task 현황

기준: `O (됨)`은 성공 smoke 실행 증거가 있는 task, `X (안됨)`은 현재 실행 불가·차단·미지원,
`△ (해결중)`은 아직 실행하지 않았거나 환경/데이터/권한 해결을 기다리는 task다.
