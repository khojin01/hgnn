# HyperGCN 환경 확인 및 node smoke 검증

- 작성 시각(KST): 2026-09-10
- 대상: HyperGCN, `hgnn-pyg`
- 현재 상태: 진행 중

## 발생한 문제

- 고정 스크립트의 첫 DBLP-A 경로는 `data/dblp_copub/data_split_0.01.pickle` 누락으로
  데이터 로딩 단계에서 중단됐다.

## 조치 내용

- HyperGCN의 Torch/PyG/torch_scatter import를 확인했다.
- 데이터가 완비된 Cora-CA에서 GPU0, 1 seed, 20 epoch node smoke를 실행했다.

## 현재 상태

- 해결됨: Cora-CA smoke가 종료 코드 0으로 완료됐고 최종 test accuracy는 24.77%다.
- 진행 중: HyperGC Table 3의 Cora-CA 기준 45.0 ± 9.5%보다 -20.23%p다. 단일 seed 설정이라
  성능 회귀로 판정하지 않으며 20-split 검증이 필요하다.
- 진행 중: DBLP-A split 파일이 제공되어야 고정 경로를 완료할 수 있다.

## 다음 담당자

- 데이터 담당자: `data/dblp_copub/data_split_0.01.pickle` 제공 여부 확인.
- env-checker: HyperGCN edge smoke 및 20-split 재현 검증 진행.
- clerk: 다음 smoke 결과를 `smoke_run.md`에 즉시 누적.
