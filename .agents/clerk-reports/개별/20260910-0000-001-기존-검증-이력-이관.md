# 기존 환경 검증 및 smoke 실행 이력 이관

- 작성 시각(KST): 2026-09-10
- 대상: 현재까지 기록된 환경 검증 및 모델 smoke 실행
- 현재 상태: 진행 중

## 발생한 문제

- GraphMAE2와 HyperGRL은 DGL GraphBolt와 Torch 2.7의 바이너리 호환 문제로 GPU
  실행이 막혀 있다.
- AllSet과 EDHNN의 기본 DBLP-A smoke 경로는 필요한
  `data/dblp_copub/data_split_0.01.pickle` 파일이 없어 실행할 수 없다.
- UniGIN smoke 실행은 사용자 승인 거부로 보류되어 있다.

## 조치 내용

- `hgnn-pyg`, `hgnn-legacy`, `hgnn-hypergcl`의 CUDA/import 상태와 실행 결과를
  내부 원장에 기록했다.
- Cora-CA에서 AllSet, EDHNN, HGNN, HNHN, MLP 단일 seed smoke 실행 결과를
  `smoke_run.md`에 이관했으며, HyperGC 논문 Table 3 평균 대비 차이도 계산했다.
- DGL 환경의 제약과 데이터/권한 차단 사유를 상태 원장에 보존했다.

## 현재 상태

- 해결됨: AllSet의 PyG 2.6.1 호환 문제는 PyG 2.0.4 적용 후 Cora-CA smoke 실행으로
  해소됐다.
- 진행 중: 실행 가능한 나머지 모델의 smoke 검증 및 20-split 재현 검증.
- 해결 불가: 현 서버에서는 DGL GraphBolt/Torch 2.7 조합의 GPU 빌드에 필요한 도구 및
  CUDA 조건이 충족되지 않는다. 호환 Torch/DGL 환경 또는 CUDA 12.8 이상과 CMake가
  제공될 때 재검토한다.
- 진행 중: DBLP-A split 파일 제공 및 UniGIN GPU 실행 권한을 기다린다.

## 다음 담당자

- env-builder: DGL 대체 실행 환경 가능 여부 확인.
- env-checker: 실행 가능한 모델의 단일 seed smoke 결과를 Clerk에 즉시 전달.
- clerk: hand-off별 한글 개별 보고서 및 smoke 결과표 누적.

## 전체 모델 task 현황

기준: `O (됨)`은 성공 smoke 실행 증거가 있는 task, `X (안됨)`은 현재 실행 불가·차단·미지원,
`△ (해결중)`은 아직 실행하지 않았거나 환경/데이터/권한 해결을 기다리는 task다.
