# MaskGAE 소스 누락 및 TriCL smoke 검증

- 작성 시각(KST): 2026-09-10
- 대상: MaskGAE, TriCL, `hgnn-pyg`
- 현재 상태: 진행 중

## 발생한 문제

- MaskGAE는 `maskgae/model.py`와 `maskgae/utils.py`가 없어 학습 스크립트가 import 단계에서
  실행될 수 없다. `.pyc` 캐시만으로는 현재 Python 환경에서 소스를 복원할 수 없다.

## 조치 내용

- MaskGAE의 디렉터리와 학습 스크립트 import 대상을 점검해 누락 파일을 확정했다.
- TriCL은 의존성 import 후 Cora-CA에서 GPU0, 1 seed, 15 epoch smoke를 실행했다.

## 현재 상태

- 해결 불가: MaskGAE는 원본 파일이 제공되기 전에는 실행할 수 없다. 소스 복원 시 재검토한다.
- 해결됨: TriCL Cora-CA smoke는 종료 코드 0, test accuracy 60.10%로 완료됐다.
- 진행 중: TriCL은 논문 T3 기준 63.4 ± 3.9%보다 -3.30%p이며 단일 seed 결과라 20-split
  재현 검증이 필요하다.

## 다음 담당자

- 사용자/소스 담당자: MaskGAE의 누락된 `model.py`, `utils.py` 원본 복원.
- env-checker: TriCL edge smoke와 20-split 재현 검증 진행.
- clerk: 후속 실행을 `smoke_run.md`에 누적.

## 전체 모델 task 현황

기준: `O (됨)`은 성공 smoke 실행 증거가 있는 task, `X (안됨)`은 현재 실행 불가·차단·미지원,
`△ (해결중)`은 아직 실행하지 않았거나 환경/데이터/권한 해결을 기다리는 task다.
