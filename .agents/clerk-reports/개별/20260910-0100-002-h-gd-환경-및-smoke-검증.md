# H-GD 환경 확인 및 node smoke 검증

- 작성 시각(KST): 2026-09-10
- 대상: H-GD (논문 표기 GGD), `hgnn-pyg`
- 현재 상태: 진행 중

## 발생한 문제

- 고정 스크립트의 `dblp_coauth`에는 `X.pt`, `news`에는 `edge_bucket.pickle`,
  `cora_cite`에는 `X.pt`가 없어 데이터 로딩 단계에서 실행할 수 없었다.

## 조치 내용

- H-GD의 의존성 import와 CUDA 사용 가능 여부를 `hgnn-pyg`에서 확인했다.
- 필요한 파일이 있는 `cora_coauth`의 스크립트 명시 설정으로 GPU0, 1 seed, 15 epoch
  smoke를 수행했다.

## 현재 상태

- 해결됨: H-GD는 `hgnn-pyg`에서 CUDA 모델 학습과 linear evaluation까지 종료 코드 0으로
  실행됐다. Cora-CA test accuracy는 30.23%다.
- 진행 중: T3의 GGD Cora-CA 기준 32.2 ± 6.3%와의 차이는 -1.97%p다. 단일 seed·15 epoch
  결과라 재현 성능 판단은 보류하고, 20-split 검증이 필요하다.
- 진행 중: 누락된 세 데이터 파일을 확보하기 전에는 해당 고정 smoke 경로를 완료할 수 없다.

## 다음 담당자

- 데이터 담당자: `dblp_coauth/X.pt`, `news/edge_bucket.pickle`, `cora_cite/X.pt` 제공 여부 확인.
- env-checker: H-GD edge smoke 및 20-split 재현 검증 진행.
- clerk: 이후 실행 결과를 `smoke_run.md`와 개별 보고서에 누적.

`△ (해결중)`은 아직 실행하지 않았거나 환경/데이터/권한 해결을 기다리는 task다.
