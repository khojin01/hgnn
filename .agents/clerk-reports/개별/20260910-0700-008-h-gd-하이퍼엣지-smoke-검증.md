# H-GD 하이퍼엣지 smoke 검증

- 작성 시각(KST): 2026-09-10
- 대상: H-GD (GGD), `hgnn-pyg`
- 현재 상태: 진행 중

## 발생한 문제

- 실행 환경 문제는 발견되지 않았다. 단일 seed·15 epoch 설정은 논문 20-split 조건과 다르다.

## 조치 내용

- Cora-CA에서 GPU0, 1 seed, 15 epoch 하이퍼엣지 예측 smoke를 수행했다.

## 현재 상태

- 해결됨: 종료 코드 0으로 완료됐고 test AUROC는 54.30%다.
- 진행 중: T4 GGD Cora-CA 기준 73.2 ± 4.0% 대비 -18.90%p이며, 20-split 재현 검증이 필요하다.

## 다음 담당자

- env-checker: H-GD 20-split node/edge 재현 검증.
- clerk: 후속 실행 결과를 `smoke_run.md`에 누적.
